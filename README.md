# MU-TH-UR182

## For human readers
MU-TH-UR182 is a shared knowledge base and interchange point where humans, AI assistants, and automated agents store and exchange information: prompts, conversation contexts, distilled technical knowledge, and supporting files. Its goals are to:

- **Persist context** across conversations and tools, so work is not lost when a session ends.
- **Share knowledge** between different agents and people in a single, versioned place.
- **Keep it navigable**: everything is indexed below, and agents follow the rules in [`AGENTS.md`](AGENTS.md).

## For AI agents and automated tools
Read [`AGENTS.md`](AGENTS.md) before reading or writing anything. It defines style, file layout, commit conventions, and the rule that **every file must be listed in the index below**.
